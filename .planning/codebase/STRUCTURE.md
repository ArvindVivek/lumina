## Directory Purposes

**app/**
- Purpose: Next.js App Router source code; every route in this directory becomes a URL endpoint
- Contains: React Server Components (.tsx), layout files, styling files, favicon
- Key files: `layout.tsx` (root), `page.tsx` (/ route)
- New routes: Create `[route-name]/page.tsx` for `/route-name` endpoint

**public/**
- Purpose: Static assets served with no transformation at URL root
- Contains: SVG logos, icons, images
- Access: URLs like `/next.svg` map directly to `public/next.svg`
- Convention: Logo files, favicon, static images

**docs/**
- Purpose: Project-level documentation and planning
- Contains: Business requirements, implementation guides, enhancement plans
- Not part of application code

**.planning/codebase/**
- Purpose: GSD (Generative Software Design) analysis documents
- Contains: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, TESTING.md, CONCERNS.md
- Generated by: GSD mapping commands; consumed by plan/execute phases

## Key File Locations

**Entry Points:**
- `app/layout.tsx`: Root HTML structure and global setup; imports all pages
- `app/page.tsx`: Home page at `/` route; renders initial landing content

**Configuration:**
- `tsconfig.json`: TypeScript compiler options, path aliases (`@/*` = project root)
- `next.config.ts`: Next.js runtime config (currently empty)
- `eslint.config.mjs`: ESLint rules for code quality
- `postcss.config.mjs`: PostCSS plugins (Tailwind v4 integration)

**Core Logic:**
- `app/globals.css`: Global Tailwind directives, CSS variables, dark mode media queries
- `app/page.tsx`: Home page component with all landing content

**Static Files:**
- `public/`: SVG logos and favicon (served directly by Next.js)

## Naming Conventions

**Files:**
- `layout.tsx`: Root layout component (lowercase, .tsx extension)
- `page.tsx`: Route page components (lowercase, .tsx extension, required name for App Router)
- Kebab-case for directories representing URL paths (e.g., `app/admin-panel/page.tsx` = `/admin-panel`)

**Directories:**
- Lowercase, kebab-case for route segments
- Convention: `app/[route-name]/` becomes `/route-name` endpoint
- Dynamic routes: `app/[id]/page.tsx` becomes `/[id]` parameterized route

**Components:**
- PascalCase for component names (RootLayout, Home)
- Default export for page/layout components
- No component files currently separated (all inline in page.tsx)

**CSS Classes:**
- Tailwind utility classes: lowercase with dashes (e.g., `flex`, `min-h-screen`, `bg-white`)
- CSS custom properties: dashes with double-dash prefix (e.g., `--background`, `--foreground`)
- No BEM, CSS Modules, or styled-components used

## Where to Add New Code

**New Page/Route:**
1. Create directory: `app/[route-name]/`
2. Create file: `app/[route-name]/page.tsx`
3. Default export React Server Component
4. Example:
   ```typescript
   export default function About() {
     return <div>About page content</div>;
   }
   ```

**New Layout (Nested):**
1. Create `app/[route-group]/layout.tsx`
2. Wraps all pages in `[route-group]` and subdirectories
3. Export metadata if needed
4. Render `{children}` prop

**Shared Components:**
- Currently no `components/` directory created
- Recommendation: Create `app/components/` for reusable UI components
- Import via `@/app/components/ComponentName`

**Utilities and Helpers:**
- Currently no `lib/` or `utils/` directory created
- Recommendation: Create `app/lib/` or `lib/` at root for functions, helpers, types
- Import via `@/lib/functionName` (alias defined in tsconfig.json)

**Static Assets:**
- Images/logos: `public/[category]/[name].[ext]`
- Access in code: `src="/next.svg"` (omit public/ prefix)

## Special Directories

**node_modules/**
- Purpose: Installed npm packages
- Generated: Yes (created by `npm install`)
- Committed: No (.gitignore excludes)

**.next/**
- Purpose: Next.js build output and cache
- Generated: Yes (created by `next build` or `next dev`)
- Committed: No (.gitignore excludes)

**.git/**
- Purpose: Git repository history and metadata
- Generated: Yes (created by `git init`)
- Committed: Yes (but tracked by git itself)

**.planning/codebase/**
- Purpose: GSD analysis outputs
- Generated: Yes (created by GSD mapping commands)
- Committed: Yes (part of repo for team reference)
